# Changelog

All notable changes to the rules and documentation of **Magical Animal Carnival** will be recorded here.

## Unreleased

## v0.2.0 - 2026-10-28

### Added

- Added the Japanese and English v0.2.0 rulebooks.
- Added a low-resolution preview sheet of the Base Set cards for public documentation.

### Changed

- Replaced **Lightning** with **Wind** in the Base Set.
- Updated the four Base Set Magical Animals assigned to Wind.
- Fixed the paper-game draft direction to **clockwise**.
- Standardized English rulebook terminology, including **Draft**, **Turn**, **Pick a Card**, **Use an Element Ability**, **Cute Score / Cool Score**, **Cute Rank / Cool Rank**, **Cute Points / Cool Points**, **Round Points**, and **Total Points**.
- Standardized Japanese rulebook terminology, including **マジカルアニマル**, **マジカルアニマルカード**, **コレクション**, **スターレベル**, **Cuteスコア / Coolスコア**, **Cute順位 / Cool順位**, **Cute勝点 / Cool勝点**, **ラウンド勝点**, and **合計勝点**.
- Aligned Japanese and English wording for common rule actions such as choosing, drawing, gaining cards, returning cards, setting cards aside, and revealing information.
- Updated the project status to reflect the Board Game Arena Studio implementation and submitted Private Alpha request.

### Clarified

- Clarified the distinction between Magical Animals as game entities and Magical Animal cards as physical cards.
- Clarified the distinction between card counts and the number of different Magical Animals.
- Clarified terminology for performer selection, Synergy resolution, Star Levels, and scoring.
- Clarified that the required safety reserve must be secured before drafting begins.

## v0.1.0 - 2026-09-24

### Added

- Initial public release of the Japanese rulebook.
- Added the English translation of the v0.1.0 rulebook.
- Rulebook links and version information added to README.
- Copyright and licensing information added to README.
